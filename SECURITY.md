# Security policy

Please do not open public issues containing notification contents, device keys, account tokens, Bluetooth captures with identifying data, or other personal information.

The current alpha is research software. It is not suitable for medical, emergency, authentication, or safety-critical notifications.

When reporting a vulnerability, provide the minimum reproducible description and redact personal/device data. Until a private reporting channel is published, open a short issue asking the maintainer for a private contact method without disclosing the vulnerability details.
